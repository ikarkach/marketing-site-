## 2. Selectel CDN

Уже настроено (проверено 2026-10-13): HTTP → HTTPS, HTTP/2 и HTTP/3, «Проксировать robots.txt», кеш на CDN по кодам ответов,
кеш в браузере 1 час. Адрес без `www` отвечает 301 на `https://www.usplitonline.ru/` (проверено).

- [ ] Вкладка «Оптимизация»: тип «Статика», включены **Gzip** и **Brotli**.
- [ ] Ответ 404: открыть несуществующий адрес (например `https://www.usplitonline.ru/proverka-404/`) — должна показываться страница 404 сайта с кодом ответа **404**, а не 200 и не ошибка CDN. Если нет — в бакете S3 на вкладке «Веб-сайт» указать страницу ошибки `404.html`.
- [ ] Перенаправления: `/projects/hisense-polupromyshlennye/` и `/blog/mnogokanalnaya-sistema-kondicionirovaniya/` сейчас переводят на новые адреса страницей с мгновенным переходом (Hugo `aliases`). Если в бакете на вкладке «Веб-сайт» есть правила перенаправления — продублировать их там как 301 (необязательно, но надёжнее).
- [ ] После каждой публикации — полная очистка кеша CDN.

## 6. Яндекс Метрика: цели

На сайте уже размечены клики (атрибут `data-goal`), Метрика отправляет их как JS-события. Осталось создать цели
в Метрике: **Настройка → Цели → Добавить цель → «JavaScript-событие»**, идентификатор:

| Цель | Идентификатор |
|---|---|
| Клик по телефону | `call_click` |
| Клик по WhatsApp | `whatsapp_click` |
| Клик по Telegram | `telegram_click` |
| Клик по MAX | `dg_social_click_max` |

Затем составная цель «Обращение» (любая из четырёх) — для отчётов и рекламы.
Проверка: открыть сайт, нажать кнопку, через несколько минут в Метрике → Отчёты → Конверсии.
