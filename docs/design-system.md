# Дизайн-система каталога Usplit

Структура каталога и шапка повторяют принципы крупных каталогов климатической техники (трёхколоночное меню, страница категории с фильтрами,
карточки с подсветкой при наведении), но стиль, тексты и код — собственные. Замеры эталона: `docs/reference/tokens.md`.

## Токены (`assets/css/ui.css`, блок `:root`)

| Токен | Значение | Где используется |
|---|---|---|
| `--c-primary` | `#155EAC` | заливка кнопок, активные «таблетки», градиенты |
| `--c-primary-text` | `#155EAC` | текст и рамки синего цвета (контраст ≥ 4.5:1) |
| `--c-primary-dark` | `#124E91` | левая колонка меню, баннер страницы |
| `--c-primary-light` | `#F4F7FB` | фон панели фильтров |
| `--grad-hover` | `linear-gradient(90deg, #155EAC 0%, #70C4DB 170%)` | подсветка карточек и плиток при наведении (0.3 с, через `::after`) |
| `--radius` | `3px` | кнопки, карточки, поля |
| `--header-h` | `70px` | высота шапки (sticky) |
| `--font-head` / `--font-body` | Montserrat / Roboto | заголовки, кнопки / основной текст (шрифты свои, `static/fonts/`) |

## Компоненты

- **Шапка** `layouts/partials/site-header.html` + `assets/js/nav.js`: логотип, меню из `data/menu.yaml`, телефон, кнопка «Оставить заявку».
  Мега-меню «Каталог» в 3 колонки (категории → подкатегории и третий уровень → блок «Монтаж под ключ»): открывается наведением (задержка 150 мс), кликом или клавиатурой, закрывается Esc и кликом вне меню. На телефоне — полноэкранное меню «гармошкой».
- **Баннер страницы** `page-banner.html` + `breadcrumbs.html`: заголовок, хлебные крошки (+ BreadcrumbList), переключатель плитка/список на страницах каталога.
- **Страница категории** `layouts/projects/category.html` + `assets/js/catalog.js`: «таблетки» типов, фильтры со счётчиками (скрываются, если в данных нет значений), сортировка, плитка/список, «Показать ещё», состояние в адресе (`?brand=hisense&inverter=1&sort=price&view=list`), на телефоне фильтры — выезжающая панель.
- **Карточка серии** `series-card.html`: фото на белом, название, бренд, число моделей, «от N ₽»; при наведении — синий градиент 0.3 с, всплывающая подсказка с мощностью/классом/шумом.
- **Заявка** `lead-modal.html` + `assets/js/lead.js`: окно с выбором «Позвонить / WhatsApp / MAX / Telegram». В WhatsApp текст с названием модели подставляется в ссылку, в MAX и Telegram копируется в буфер обмена. Данные посетителя не собираются и не хранятся.
- **Страница серии**: шорткод `layouts/shortcodes/catalog.html` (данные `data/catalog.json`): фото, особенности, кнопки «Узнать цену» / «Заказать с монтажом», таблицы моделей, Product + AggregateOffer.

## Данные

`scripts/build_catalog.py` собирает `data/catalog.json` (только розничные цены) и `data/series.json` (27 серий: бренд, тип, инвертор, тепловой насос, мощность, класс, шум, фото) из прайс-листов. Фото готовит `scripts/photos.py` (WebP, до 1000 px). Сверка цен: `scripts/verify_catalog.py` (250 цен).
Добавить серию: строка в прайсе → `python scripts/build_catalog.py --photos ...` → проверить `verify_catalog.py`.

## Производительность CSS

Тема Introduction подключает полный Bulma, FontAwesome и academicons в светлой и тёмной версиях (≈470 КБ). В проекте:
`assets/sass/style.sass` и соседние `_*-import.sass` (переопределяют файлы темы, сама тема не менялась) оставляют только используемое — ≈64 КБ.
Кастомные `ui.css` и `site.css` склеиваются и минифицируются в `layouts/partials/head/css.html`. Новая иконка FontAwesome: дописать её код в `assets/sass/_fontawesome-import.sass`.

## Тема

Сайт всегда светлый (hugo.toml: 	hemeStyle = "light", :root { color-scheme: light }): при тёмной теме браузера страницы не темнеют. Тёмной темы в CSS нет.
