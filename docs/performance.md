## Что сделано

**Шрифты**
- Иконки Font Awesome: вместо полных шрифтов темы (251 КБ) — урезанные до 12 используемых иконок (1,7 КБ + 1 КБ),
  `static/fonts/icons/`, хеш в имени. Скрипт: `scripts/subset_icons.py` (новая иконка — дописать код в `_fontawesome-import.sass` и запустить).
- Montserrat и Roboto: только используемые толщины (400–600 и 500–600), латинские файлы — только нужные символы.
  128 КБ → 90 КБ. Скрипт: `scripts/subset_text_fonts.py`, оригиналы — `assets/fonts-src/`.
- `@font-face` перенесены в `<head>` (`layouts/partials/head/fonts.html`), кириллические файлы — `preload`; везде `font-display: swap`.

**CSS**
- Bulma и стили сайта — один файл с хешем в имени (`layouts/partials/head/css.html`).
- Критический CSS: после сборки `scripts/critical-css.mjs` (beasties 0.4.3) встраивает в каждую страницу правила, нужные её разметке (~22 КБ, ~5 КБ сжато),
  полный файл подключается без блокировки отрисовки. В CI — шаг «Inline critical CSS» в `.github/workflows/selectel.yaml`.
  Существующие `<style>` (шрифты, `<noscript>` в шапке) инструмент не трогает.

**JavaScript**
- Все скрипты сайта — один файл с `defer` и хешем в имени (`layouts/partials/footer/scripts.html`).
- jQuery (≈87 КБ) и OwlCarousel больше не грузятся на всех страницах: только там, где действительно выводится карусель
  (`layouts/partials/projects/has-carousel.html`; сейчас таких страниц нет).
- Яндекс.Метрика загружается после основного контента: при первом действии посетителя или через 3 с после загрузки.
  Вызовы `ym()` и цели до этого копятся в очереди и не теряются.

**Изображения и сдвиги вёрстки**
- Логотип — WebP (11 → 7 КБ); у всех картинок `width`/`height`; ниже первого экрана — `loading="lazy"`,
  первое крупное фото (галерея модели, первая карточка серии) — `fetchpriority="high"`.
- Фото в карточках серий занимают блок целиком (`object-fit: contain`) — при загрузке ничего не сдвигается.
- Список серий в фильтре каталога свёрнут до 6 пунктов уже в HTML, а не скриптом — фильтр не «прыгает».

## Настройки Selectel CDN

В панели Selectel CDN срок кеша задаётся на весь CDN-ресурс (по классам ответов), а не по путям; правила по путям есть только в API.
Настроено 2026-10-10 (CDN → CDN-ресурсы → ресурс сайта):

**Основное**
- «Использовать HTTP2», «Использовать HTTP3», «Автоматически перенаправлять HTTP на HTTPS» — включены; «Использовать только HTTPS» — выключено.
- Поисковая индексация — «Проксировать robots.txt» (иначе CDN отдаёт свой robots.txt с `Disallow: /`).

**Кэширование**
- «Включить настройки кэширования» — да; «Игнорировать заголовки управления кэшированием» — нет.
- Время на CDN: 2xx — 1 день, 3xx — 1 час, 4xx — 10 минут, 5xx — не кэшировать.
- Время в браузере — 1 час (значение действует на весь сайт, включая HTML: больший срок задерживает обновления у повторных посетителей).
- «Кэшировать контент с учётом query string» — нет (фильтры каталога `?brand=…` работают в браузере, страница одна).
- По желанию: «Отдавать последнюю версию закэшированного контента, если источник недоступен» — ошибки 5xx и таймаут.

**Оптимизация**
- Тип оптимизации доставки — «Статика»; сжатие — Gzip и Brotli.

**Бакет S3** (S3 → Бакеты → usplitonline → Конфигурация)
- Cache-Control — «Не настроено» (значение там действует на все файлы бакета, включая HTML).

### Длинный кеш для CSS/JS/шрифтов (возможное улучшение)
У CSS, JS и иконочных шрифтов хеш в имени, поэтому браузер мог бы хранить их год (`Cache-Control: public, max-age=31536000, immutable`),
а HTML — не кешировать. Это делается заголовком на каждом файле при загрузке в S3 (`s3cmd sync --add-header` в `selectel.yaml`),
а не в панели CDN. Пока не включено: меняет деплой, проверить можно только на реальном хранилище.

### После каждой публикации

Сбросить кеш CDN (полная очистка, до 15 минут), затем проверить главную в PageSpeed Insights
(https://pagespeed.web.dev/ → https://www.usplitonline.ru/) — мобильная и десктопная версии.
Сжатие проверяется в браузере: F12 → Network → CSS-файл → Headers → `content-encoding: br` (или `gzip`).
