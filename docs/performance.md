## Что сделано

**Шрифты**
- Иконки Font Awesome: вместо полных шрифтов темы (251 КБ) — урезанные до 12 используемых иконок (1,7 КБ + 1 КБ),
  `static/fonts/icons/`, хеш в имени. Скрипт: `scripts/subset_icons.py` (новая иконка — дописать код в `_fontawesome-import.sass` и запустить).
- Montserrat и Roboto: только используемые толщины (400–600 и 500–600), латинские файлы — только нужные символы.
  128 КБ → 90 КБ. Скрипт: `scripts/subset_text_fonts.py`, оригиналы — `assets/fonts-src/`.
- `@font-face` перенесены в `<head>` (`layouts/partials/head/fonts.html`), кириллические файлы — `preload`; везде `font-display: swap`.

**CSS**
- Bulma и стили сайта — один файл с хешем в имени (`layouts/partials/head/css.html`).
- Критический CSS: после сборки `scripts/critical-css.mjs` (beasties 0.4.3) встраивает в каждую страницу правила, нужные её разметке (~22 КБ, ~5 КБ сжато),
  полный файл подключается без блокировки отрисовки. В CI — шаг «Inline critical CSS» в `.github/workflows/selectel.yaml`.
  Существующие `<style>` (шрифты, `<noscript>` в шапке) инструмент не трогает.

**JavaScript**
- Все скрипты сайта — один файл с `defer` и хешем в имени (`layouts/partials/footer/scripts.html`).
- jQuery (≈87 КБ) и OwlCarousel больше не грузятся на всех страницах: только там, где действительно выводится карусель
  (`layouts/partials/projects/has-carousel.html`; сейчас таких страниц нет).
- Яндекс.Метрика загружается после основного контента: при первом действии посетителя или через 3 с после загрузки.
  Вызовы `ym()` и цели до этого копятся в очереди и не теряются.

**Изображения и сдвиги вёрстки**
- Логотип — WebP (11 → 7 КБ); у всех картинок `width`/`height`; ниже первого экрана — `loading="lazy"`,
  первое крупное фото (галерея модели, первая карточка серии) — `fetchpriority="high"`.
- Фото в карточках серий занимают блок целиком (`object-fit: contain`) — при загрузке ничего не сдвигается.
- Список серий в фильтре каталога свёрнут до 6 пунктов уже в HTML, а не скриптом — фильтр не «прыгает».

## Настройки Selectel CDN (вносите вы)

Названия пунктов в панели могут отличаться — ориентируйтесь на смысл. Заголовки `Cache-Control` можно задать правилами CDN по пути.

### Кеширование

| Что | Пути | Cache-Control для браузера | Время кеша на CDN |
|---|---|---|---|
| CSS и JS с хешем в имени | `/css/*`, `/js/*` | `public, max-age=31536000, immutable` | 1 год |
| Иконочные шрифты с хешем | `/fonts/icons/*` | `public, max-age=31536000, immutable` | 1 год |
| Обработанные Hugo картинки (в имени `_hu_`) | `*_hu_*` | `public, max-age=31536000, immutable` | 1 год |
| Шрифты сайта (имена без хеша) | `/fonts/*.woff2` | `public, max-age=2592000` (30 дней) | 30 дней |
| Фото моделей и картинки главной | `/images/*` | `public, max-age=2592000` (30 дней) | 30 дней |
| Логотип, favicon, og-image | `/*.png`, `/*.webp` в корне | `public, max-age=604800` (7 дней) | 7 дней |
| HTML-страницы, `sitemap.xml`, `robots.txt`, `index.xml` | всё остальное | `no-cache` (браузер каждый раз сверяется с CDN) | до 1 часа + сброс кеша после каждого деплоя |

Важно:
- Не включайте «игнорировать Cache-Control» для HTML с большим сроком: иначе после публикации посетители долго видят старые страницы.
- Старые CSS/JS деплой специально не удаляет (страницы из кеша должны находить свои стили) — длинный кеш для них безопасен.
- Если поменяются шрифты сайта (`/fonts/*.woff2` без хеша), после деплоя сбросьте кеш CDN для `/fonts/*`.

### Сжатие

- Включить **Brotli** и **gzip** (brotli — для браузеров, которые его поддерживают, gzip — для остальных).
- Сжимать типы: `text/html`, `text/css`, `text/javascript`, `application/javascript`, `application/json`, `application/xml`,
  `application/rss+xml`, `image/svg+xml`, `text/plain`.
- Не сжимать повторно: `font/woff2`, `image/webp`, `image/png`, `image/jpeg` — они уже сжаты.

### Прочее

- HTTP/2 (и HTTP/3, если есть в панели) — включить.
- Перенаправление HTTP → HTTPS — включить.
- `Vary: Accept-Encoding` для сжатых ответов — оставить (обычно CDN ставит сам).

### После каждой публикации

Сбросить кеш CDN (полностью или как минимум HTML-страницы), затем проверить главную в PageSpeed Insights
(https://pagespeed.web.dev/ → адрес https://www.usplitonline.ru/) — мобильная и десктопная версии.
